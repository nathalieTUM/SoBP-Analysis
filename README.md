
# Sustainability-oriented Business Process Analysis — Supplementary Material

[![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/)

This repository contains the supplementary material accompanying a scientific
publication **"Towards Sustainability-oriented Business Process Analysis using Process Mining"**
(BPM4S Workshop, 2026). It covers a data availability analysis of sustainability
metrics in SAP S/4HANA, an enriched Procure-to-Pay (P2P) event log, and the
resulting sustainability dashboard.

> This material is associated with a scientific publication (accepted,
> forthcoming 2026, Springer Nature Switzerland AG). The supplementary
> material is released independently under CC BY 4.0.

---

## Contents

- `sap_sustainability_mapping.xlsx` — Mapping of 144 process-level sustainability
  metrics against data availability in a standard SAP S/4HANA system
  (directly available, indirectly available, extendable, not present).
- `enriched_p2p_event_log.xes` — Enriched Procure-to-Pay (P2P) event log,
  extended with transport emission, material, and vendor sustainability attributes.
- `P2P Sustainability Dashboard/` — Screenshots of the SAP Signavio sustainability dashboard
  (Process Overview, Transport Emissions, Social Metrics, Vendor Compliance).

---

## Data Provenance

The underlying process data is based on the "Global Bike" fictitious company
dataset, used within the SAP UCC curriculum. Dashboard screenshots depict the
SAP Signavio user interface. All derived material (mapping, enrichment
attributes) is original work by the authors.
